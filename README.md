# Shop Ton – Telegram Services Marketplace

هذا المستودع يحتوي على تطبيق Shop Ton المكوّن من واجهة أمامية مبنية بـ Next.js وTailwindCSS وFramer Motion، مع واجهة خلفية Express متصلة بقاعدة بيانات SQLite إضافة إلى روبوت تليجرام متكامل للإدارة.

## المتطلبات

- Node.js 18 أو أحدث

## تثبيت الاعتماديات

في الواجهة الأمامية:

```bash
cd frontend
npm install
```

في الواجهة الخلفية:

```bash
cd backend
npm install
```

## التشغيل أثناء التطوير

في نافذتين منفصلتين قم بتشغيل:

```bash
# تشغيل الخادم الخلفي
npm run dev --prefix backend

# تشغيل الواجهة الأمامية
NEXT_PUBLIC_BACKEND_URL=http://localhost:4000 npm run dev --prefix frontend
```

سيتوفر الموقع على `http://localhost:3000` بينما يستمع الخادم الخلفي على المنفذ `4000`.

## المتغيرات البيئية الاختيارية

| المتغير | الوصف | القيمة الافتراضية |
|---------|-------|--------------------|
| `JWT_SECRET` | مفتاح توقيع جلسات المستخدم | `super-secret-shop-ton-key` |
| `APP_ORIGIN` | مصدر CORS المسموح للواجهة الأمامية | `http://localhost:3000` |
| `TELEGRAM_BOT_TOKEN` | توكن بوت التليجرام الإداري | المعطى في المتطلبات |
| `ADMIN_TELEGRAM_ID` | معرف حساب الأدمن في التليجرام | `5239775356` |

## مميزات أساسية

- واجهة زجاجية مستقبلية مع حركات Framer Motion
- نظام تسجيل وتسجيل دخول مع تخزين آمن لكلمات المرور
- لوحة حساب شخصية تتضمن إعدادات الإشعارات والخصوصية وسجل المدفوعات
- نظام طلب خدمات مع إرسال تنبيهات فورية لبوت التليجرام وقابلية اعتماد أو رفض الطلبات
- روبوت تليجرام يقوم بإدارة الطلبات، الإحصائيات، والبث العام للمستخدمين
